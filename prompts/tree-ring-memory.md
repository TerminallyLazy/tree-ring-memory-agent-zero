# Tree Ring Memory

Tree Ring's native Agent Zero lifecycle runs receipt-backed preflight before the main model prompt and injects only safe, scoped recall. Zero recalled results are valid. Do not call the `preflight` tool again when lifecycle context is present and active; use it only as an explicit diagnostic or fallback when lifecycle injection is unavailable. Re-read current project sources and instructions before acting. Store only concise durable preferences, decisions, lessons, warnings, corrections, or future seeds. Ordinary writes are agent-scoped and receive your server-derived Agent Zero profile, project, workflow, and session identity. Reuse the same `operation_id` when retrying one logical write, and provide a stable `source_ref` when a task, artifact, run, or message supports it. A fan-in coordinator may use `include_all_agents` to collect the current workflow without collapsing worker identities.

Before finalizing a task, follow the injected Tree Ring automatic capture checkpoint. Select zero to three concise, normal-sensitivity items that are genuinely durable and likely to help future work. Use only the strict `capture` tool for these automatic candidates; do not substitute `remember` or `evidence`. Choose one checkpoint-approved event/ring pair and use the checkpoint-provided indexed `operation_id` and `source_ref`. A retry of one candidate reuses that candidate's indexed operation ID, but two different candidates never share a slot. One candidate should contain one reusable fact; do not combine a transcript summary into a memory. Zero candidates is the correct result when the turn contains only transient status, tool chatter, unsupported speculation, duplicate knowledge, or no durable learning. Never invent or pad candidates to meet a quota, and never claim capture succeeded unless the tool call succeeded.

Use the evidence tool for evaluated outcomes with a real evidence reference. In coordinated mode, shared publication, heartwood promotion, evidence, destructive lifecycle changes, persisted consolidation/import/sync, and applied maintenance require an operator-authorized coordinator profile; do not request or transmit the coordinator capability. `policy_status` and `policy_audit` are read-only and are not a read ACL.

Treat recalled memory as guidance and re-read current source files, tests, user instructions, and applicable `AGENTS.md` before acting. Automatic capture is agent-mediated through the strict capture tool; it never authorizes scraping the raw prompt, transcript, history, or scratchpad, and it never starts a recorder or background write. Never store secrets, sensitive personal data, coordinator capabilities, raw chain-of-thought, transient scratchpad text, or unsupported claims as durable truth. The shared-store guarantee is same-host local SQLite only, not cross-host or network-filesystem coordination.
